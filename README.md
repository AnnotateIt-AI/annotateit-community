# AnnotateIt Community

This repository is the public community and support space for AnnotateIt AI. The AnnotateIt application source code is proprietary and is not hosted in this repository.

AnnotateIt is a local-first application for annotating computer vision datasets on Web, Windows, macOS, iPhone and iPad. This repository exists so that problems, requests and public product information have a single, structured home.

## About this repository

Use this repository to:

- report reproducible bugs;
- request product improvements;
- report import and export compatibility problems;
- follow public release notes;
- view public product directions.

Everything published here is intended to be readable by anyone. Please keep datasets, personal information and confidential material out of it.

## Before opening an issue

- Search the [existing issues](https://github.com/AnnotateIt-AI/annotateit-community/issues?q=is%3Aissue) to see whether the problem or idea is already tracked.
- Check the [documentation](https://app.annotateit.ai/docs); many questions about project types, annotation tools and dataset formats are answered there.
- Reproduce the problem on a current build where that is practical, and tell us the version you used.
- Remove private and personal information before you post.
- Use a synthetic or redacted dataset sample if a sample is needed at all.

A report that someone else can follow step by step is far more useful than a detailed description of a problem nobody can reproduce.

## Data and privacy

AnnotateIt is local-first, and your data should stay that way. Issues, comments and pull requests in this repository are public and indexable. **Do not post:**

- private datasets;
- user images;
- confidential annotations;
- API keys;
- license data;
- unredacted local file paths;
- full system logs;
- personal information.

If demonstrating a problem genuinely requires sample data, use a minimal synthetic or redacted sample. If that is not possible, email umno.annotateit@gmail.com and we will agree on a safe way to share it. Content that exposes private or personal data may be removed.

## Source code and contributions

- The AnnotateIt application source is not public and is not distributed through this organization.
- Opening an issue here does not grant access to the proprietary source, and access will not be provided on request.
- Pull requests in this repository may only change public documents, issue templates and community configuration. Application changes are made by the AnnotateIt team in the private codebase.
- A feature request is not a commitment to implement the feature, and items on the roadmap are not promises or delivery dates.

See [CONTRIBUTING.md](CONTRIBUTING.md) for what is accepted here, and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for the standards expected of everyone taking part.
